Z-score alone misses many large drops on lines whose sales swing a lot day to day; the 3x rule catches every one of them, so the gate uses both. Subtle 1.5x changes mostly get through: they sit inside normal day-to-day variation, so they show up later as drift (step 06) and in the waste gate instead.
